Yes, Vercel offers a dedicated object storage solution exactly for this use case called **Vercel Blob**.

It is designed to handle unstructured data like user-generated uploads (avatars, documents, images, and videos) without forcing you to manually configure external cloud buckets like AWS S3 or Google Cloud Storage.

---

## Key Features

* **Framework Integration:** It has a highly intuitive, promise-based API (`@vercel/blob`) that feels native if you are using frameworks like Next.js, SvelteKit, or Nuxt.
* **Edge/CDN Powered:** Uploaded files are served from a global network via unique, secure URLs and benefit from automatic caching.
* **Client vs. Server Uploads:**
* **Server Uploads:** You can forward files through a backend API route. However, keep in mind that Vercel’s Serverless Functions have a request body size limit of **4.5MB**.
* **Client Uploads:** For larger files (it supports up to 5TB via multipart uploads), you can bypass the serverless payload limit by generating a token on the server and uploading the file **directly from the client browser** to Vercel Blob.

---

## Quick Example (Serverless Route Handler)

If you are handling smaller files or avatars in a TypeScript backend route, it looks like this:

```typescript
import { put } from '@vercel/blob';

export async function PUT(request: Request) {
  const form = await request.formData();
  const file = form.get('file') as File;
  
  // Uploads the file and handles cache/naming automatically
  const blob = await put(`avatars/${file.name}`, file, { 
    access: 'public',
    addRandomSuffix: true // Prevents accidental overwrites
  });

  return Response.json(blob);
}

```

Vercel provides a generous starting tier for its storage products:
