## State at v0.1.0

The application is a Next.js frontend (originally scaffolded with create-next-app)
deployed via Docker Compose to self-hosted GitHub Actions runners. The most recent
work on `develop` focused on Docker/CI fixes and an incomplete Particle Network
wallet integration.

**The frontend was not rendering** at this commit due to configuration and startup
issues. The Particle Network integration was incomplete and had unresolved security
vulnerabilities flagged in code review.

## Particle Network Integration Status

### What was merged (PRs #11, #13, #14)

The Particle Network integration was authored by **shervin210** across three PRs:

- **PR #11** (`api-connection-particle`): Added `@particle-network/connectkit`, social
  login (email, google, apple, twitter, github), wallet registration flow, API auth
  routes. **Merged with known critical issues** flagged by reviewer ImanAlibeigi:
  1. **Replay attack vulnerability** -- static signing message instead of server-generated
     challenge/nonce
  2. **`ethers` v5/v6 conflict** in package.json
  3. **Hardcoded `.infrafund.test` domain** that breaks production
  4. **Undefined `message` variable** in `api/auth/login/route.ts` (runtime crash)
  5. Non-English comments and debug `console.log` statements
- **PR #13** (`api-connection-particle`): Follow-up fix for ethers version / Docker build.
  +4,884/-3,390 lines.
- **PR #14** (`bug/docker-env`): Docker env configuration fix related to Particle.

### Assessment

The Particle integration is **incomplete and has unresolved security issues**. The
`AutoWalletRegister.tsx` component is a debug/test harness showing raw user info, not
a production login flow. The security concerns from PR #11 reviews were never addressed.

**Decision:** Remove Particle Network and replace with **Openfort + Viem** for better
type safety, built-in gas sponsorship, and no vendor lock-in.
