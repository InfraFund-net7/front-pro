# v1.2.6 — Load Cesium Viewer from CDN

## Summary

This release stabilizes the Cesium digital twin viewer on Vercel by loading the CesiumJS runtime and widget CSS from Cesium's official CDN instead of bundling or serving Cesium runtime files from the Next.js app.

## Highlights

- Switched the project 3 Cesium viewer to load `Cesium.js` from the official Cesium CDN.
- Loads Cesium widget styles from the matching CDN release path.
- Removed the local Cesium npm dependency and generated `public/cesium` asset pipeline.
- Restored the build flow to only run Prisma generation before `next build`.
- Kept Cesium Ion token and asset preflight checks for clearer runtime diagnostics.
- Added dedicated user-facing states for token checks, runtime loading, token rejection, asset access issues, and CDN/runtime failures.
- Avoided Vercel production bundle parsing issues caused by Cesium's generated runtime code.

## Validation

- Confirmed the CDN-based viewer loads successfully on localhost.
- Confirmed the CDN-based viewer loads successfully on the Vercel deployment.
- Ran `npm run format` successfully.
- Ran `npm run build` successfully.
