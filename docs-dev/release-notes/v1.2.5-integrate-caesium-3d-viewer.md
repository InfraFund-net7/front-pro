# v1.2.5 — Integrate Cesium 3D Viewer

## Summary

This release adds a Cesium Ion 3D Tiles viewer for the project 3 digital twin page and updates the London wind turbine pilot to be treated as an operational project.

## Highlights

- Added the Cesium dependency and a client-side Cesium Ion viewer for asset `4764199`.
- Added a `/cesium/[...path]` asset route so Cesium runtime resources load correctly in Next.js.
- Added `NEXT_PUBLIC_CESIUM_ION_ACCESS_TOKEN` to the sanitized environment template.
- Renamed project 3 from Cornwall to `London Wind turbine Pilot #3`.
- Marked project 3 as operational and replaced its construction milestones with power generation metric cards.
- Updated digital twin page titles to use the project name in the app header.
- Removed duplicate header bars from the 3D viewer panels and tightened digital twin page spacing.
- Updated the developer dashboard project 3 card to show the London operational state.
