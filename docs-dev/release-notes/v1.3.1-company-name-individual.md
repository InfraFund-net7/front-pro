# v1.3.1 — Individual company name handling

## Summary

This patch release ensures individual accounts are stored with `companyName = 'INDIVIDUAL'` during Openfort exchange.

## Highlights

- Force `companyName` to `INDIVIDUAL` for users with `type === 'individual'`.
- Keep organization accounts using the submitted organization name.
