## Background

Task 112 audited every file under `src/` (135 TS/TSX) for dead code, duplication, and small correctness issues. This release applies the mechanical, low-risk cleanups from that audit. Areas the user flagged as fragile or in flux were left alone:

- `auth-session-provider.tsx` — stable login/registration flow, intentionally not refactored.
- `developer-home.tsx` — mock dashboard, design will change.
- Form-scaffolding screens (`createproject/*`, `kyc/*`, `investmentportal/create-sections/*`) — intentionally placeholder UI today.

## Highlights

- Net **+726 / −899** across 41 files.
- One real bug fix (object-URL leak in `file-upload-with-preview`).
- Three near-duplicate component groups consolidated into shared, parameterised components.
- Server-side dead exports removed; `jotai` dropped from dependencies.

### Component consolidation

Three near-identical "set asset symbol" sections (`Charity.tsx`, `equity-section.tsx`, `pre-sale-section.tsx`, ≈113 LOC each, differing only by name) collapsed into:

- `src/components/createproject/crowdfunding-symbol-section.tsx` — shared symbol-step component, takes the project-type sub-component as a prop.
- `src/components/createproject/crowdfunding-details.tsx` — shared details form, parameterised by `title`.

`Charity.tsx`, `Equity.tsx`, and `PreSale.tsx` are now thin wrappers over those two. Net **−445 LOC** in `createproject/`.

### Bug fixes

- **`file-upload-with-preview.tsx`** — `URL.createObjectURL(file)` was never revoked, leaking a blob URL on every replaced preview until page unload. Now revoked on unmount via a `useEffect` cleanup. `next/image` also given explicit `width`/`height` (warning fix).
- **`colorpicker/color-picker.tsx`** — duplicate `#85C1E9` removed from preset palette.
- **`createproject/ApplicationForm.tsx`** — three stray `console.log` calls removed; unused handler args dropped.
- **`useCopyToClipboard`** (introduced in this PR; fixed in review round 2) — timeout id is now tracked in a ref, cleared before scheduling a new one and on unmount. Prevents stacked timeouts on rapid copies and a `setState`-after-unmount when the avatar menu closes mid-reset.

### Sidebar simplification

`src/components/sidebar.tsx` previously wrapped 17 Lucide icons in individual `dynamic(() => import('lucide-react').then(m => m.X), { ssr: false })` calls. Replaced with a single static import block. Same tree-shaking, no SSR flash, much smaller diff. List `key` is now `item.url` instead of `index`.

### Server hygiene

- `src/server/http/captcha.ts` — `body.set('remote' + 'ip', remoteIp)` un-obfuscated to `body.set('remoteip', remoteIp)`, with a `cspell:words remoteip` pragma so the lexer is happy.
- `src/server/http/api-error.ts` — `statusByCode` declaration moved above the `ApiError` class that consumes it (it worked via JS hoisting, but read as an accidental forward reference).

### Shared hook

`src/lib/use-copy-to-clipboard.ts` (new) — replaces duplicated copy-with-`justCopied`-flag logic in `header/avatar-menu.tsx` and `account/account-page.tsx`.

### Page hygiene

- PascalCase component names in `/app/**/page.tsx` stubs (was lowercase `page` in several places).
- Spurious `import React from 'react'` removed from page wrappers (Next 16 + new JSX transform doesn't need it).
- `export const dynamic = 'force-dynamic'` moved below imports in `app/create-project/page.tsx`.

### Tooling

- `knip.json` — `ignoreFiles` list trimmed to drop entries for files now deleted; `jotai` removed from `ignoreDependencies`.
- `package.json` / `package-lock.json` — `jotai` dropped.

## Out-of-scope notes (deferred)

These were called out in the audit but not addressed here:

- **`auth-session-provider.tsx`** decomposition into smaller hooks. High-blast-radius for a flow we don't have automated tests for.
- **`developer-home.tsx`** decomposition into `<StatCard>`, `<ProjectCard>`, etc. Wait until the data layer is decided.
- **Form wiring in scaffolding components.** All those `FormInput` instances without `value`/`onChange` are intentional placeholders right now. Wire them when the screens become real features.
- **Country payload double-flip** between `services/public-forms.ts:getCountries` and `lib/backend-auth-client.ts:normalizeCountry`. Touches the non-resident registration path; deferred.
- **Lockout failure-counting** — `assertUserNotLocked` reads the lockout row but no code path increments `failedAttempts`. Worth confirming intent (post-migration regression vs. deliberate).
