# v1.2.7 — GLTF Metadata Inspection and Responsive Digital Twin UI

## Summary

This release adds model-agnostic click-to-inspect metadata support for the glTF digital twin viewer and improves the page layout for narrow screens. Users can click model components and inspect available metadata as plain name-value pairs without requiring a fixed metadata schema.

## Highlights

- Added generic glTF metadata extraction from clicked R3F objects, parent nodes, project component config, and top-level `extras.elements` catalogs.
- Added a reusable metadata inspector panel with Ground/Light view controls and compact scrollable key-value rows.
- Added a draggable desktop divider between the 3D viewport and metadata panel, defaulting to a 66/34 split and allowing up to 50/50.
- Made the metadata panel stack below the viewport on narrower screens.
- Added reusable `AppPageHeader` for consistent page title/action layout.
- Reduced page title sizing and made narrow headers stack as actions first, title below.
- Added a mobile navigation drawer so the sidebar is available from a menu button on narrow screens.
- Aligned digital twin status chip spacing with the viewport spacing rhythm.

## Implementation notes

- The first milestone intentionally avoids mapping arbitrary model metadata into fixed application fields.
- Metadata is represented as generic `MetadataRecord` / `MetadataValue` types.
- Known identity fields such as `externalId`, `id`, `name`, `displayName`, and `modelNodeName` are only used for matching and panel headings.
- Future database-backed metadata should use PostgreSQL `jsonb` first, then promote frequently queried keys to typed columns only when needed.
