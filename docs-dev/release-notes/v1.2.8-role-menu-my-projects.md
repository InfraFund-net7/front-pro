# v1.2.8 — Role-Based Navigation and My Projects

## Summary

This release adds role-aware sidebar navigation and introduces a My Projects surface backed by an account-project-role relationship. It prepares the app for accounts to hold different roles across different projects.

## Highlights

- Replaced split sidebar menu arrays with one ordered role/type navigation registry.
- Added role-specific menu visibility for Client, Investor, Contractor, DAO, and Auditor accounts.
- Added a global role badge next to the page title in the app header.
- Added My Projects below Explore Projects for supported roles.
- Added `ProjectAccountRole` to link accounts, projects, and roles.
- Backfilled existing project owners into the new project role link table.
- Added placeholder pages for newly visible role-specific menu routes.

## Implementation notes

- Product-facing onboarding roles are normalized before storage: `client` maps to `project_owner`, and `dao` maps to `governance`.
- Restricted menu items are hidden rather than rendered disabled.
- Menu links point to stable routes; pages and APIs remain responsible for role-aware data and action access.
- New project drafts create a matching project role link using the account's current role.
