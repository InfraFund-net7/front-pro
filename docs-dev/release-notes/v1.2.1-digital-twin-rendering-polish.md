# v1.2.1 — Digital Twin Rendering Polish

**Date:** 2026-05-12
**Status:** Draft
**Branch:** `gltf`
**Previous release:** `v1.2.0`

## Summary

Improves the AI-Digital Twin 3D viewer so turbine models are easier to inspect and interact with in the project detail pages.

## User-visible changes

- Switched the model viewport to a neutral grey scene background.
- Added viewer controls for toggling the ground plane and key light.
- Added a square ground plane with a visible grid.
- Improved default lighting so white turbine geometry has stronger shape definition.
- Enabled model shadow casting and ground shadow receiving.
- Normalized model placement from its loaded bounds so the ground plane sits under the turbine instead of depending on model-origin coordinates.
- Prevented Ground/Light toggles from resetting the current camera position or zoom.

## Technical changes

- The viewer now computes a loaded model bounding box with Three.js `Box3` and offsets the model to sit on `y = 0`.
- Drei `Bounds` is used for initial model fit only, avoiding camera refits when visual toggles change.
- The directional light was moved higher and its shadow camera bounds were expanded to avoid clipped turbine shadows.
