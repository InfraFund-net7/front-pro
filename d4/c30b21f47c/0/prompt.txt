```
Openfort is built for "Invisible Wallets." Its modular nature allows you to treat the wallet as a resource you grant to a user only after they satisfy your backend conditions.

Phase 1 (Login): User clicks "Login with Google." Use Openfort's Headless Auth or your own OIDC provider. At this point, you have their email/ID, but no wallet exists.

Phase 2 (Qualify): Redirect the user through your survey pages. Store their answers in your database, linked to their email/ID.

Phase 3 (Decision): * If Disqualified: Show a "Thank You" page and terminate the session. No on-chain account was ever created.

If Qualified: Call the Openfort API to createPlayer and deployWallet.

Result: The user is now "Web3-enabled" and can proceed to sign transactions.
```
