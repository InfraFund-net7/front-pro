To fully wipe and reset your database in Neon, you have a couple of options depending on your branch setup:

## Reset from Parent Branch

If your branch has a parent branch, you can use the **Reset from parent** feature to completely overwrite your branch with the latest data and schema from its parent.[(1)](https://neon.com/docs/guides/reset-from-parent)

**Using the Neon Console:**
1. Go to the **Branches** page
2. Select the branch you want to reset
3. Click **Reset from parent** from the **Actions** menu or the **Last data reset** panel[(1)](https://neon.com/docs/guides/reset-from-parent)

**Using the Neon CLI:**

```bash
neon branches reset <branch-id|name> --parent
```
[(1)](https://neon.com/docs/guides/reset-from-parent)

For example:

```bash
neon branches reset br-divine-glade-19837478 --parent --project-id=raspy-water-84552850
```
[(2)](https://neon.com/blog/announcing-branch-reset)

**Important notes:**
- This is a complete overwrite, not a merge. Any local changes on your branch will be lost.[(1)](https://neon.com/docs/guides/reset-from-parent)
- Existing connections will be temporarily interrupted but will automatically re-establish once the reset completes.[(1)](https://neon.com/docs/guides/reset-from-parent)[(2)](https://neon.com/blog/announcing-branch-reset)
- Your connection details (hostname, connection string) remain the same.[(1)](https://neon.com/docs/guides/reset-from-parent)

## Alternative: Manual Database Cleanup

If you want to clean specific databases without resetting the entire branch, you can connect to your database and manually drop/recreate databases or truncate tables using standard PostgreSQL commands.

## Reset a Branch Using the CLI

```bash
neon branches reset <id|name> --parent
```

[(2)](https://neon.com/docs/guides/branching-neon-cli#branch-expiration)

This resets the `feature/user-auth` branch to match the latest state of its parent branch.[(2)](https://neon.com/docs/guides/branching-neon-cli#branch-expiration)

## If Your Branch Has Child Branches

If the branch you want to reset has child branches, you need to use the `--preserve-under-name` parameter to save the current state under a new name:[(2)](https://neon.com/docs/guides/branching-neon-cli#branch-expiration)


This preserves the branch's latest state under `feature/user-auth-backup` before resetting, allowing child branches to maintain their parent relationship.[(2)](https://neon.com/docs/guides/branching-neon-cli#branch-expiration)

However, you can **delete and recreate your databases** using the Neon CLI to achieve a fresh start:

## Option 1: Delete and Recreate Your Database

**1. List your databases:**[(2)](https://neon.com/docs/reference/cli-databases)

```bash
neon databases list --project-id <your-project-id>
```
[(2)](https://neon.com/docs/reference/cli-databases)

Alternatively, connect to your database using `psql` or another SQL client and manually drop all tables/schemas, then recreate them as needed.

## Note About Root Branches
